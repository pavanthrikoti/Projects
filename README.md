# Personal Expense Tracker

Welcome to my **Personal Expense Tracker**, a sleek and functional web application designed to help you manage your finances effortlessly! Built with modern web technologies, this project showcases my skills as a software developer. Check it out live at: **[https://free-personal-expense-tracker.netlify.app/](https://free-personal-expense-tracker.netlify.app/)**.

---

## Overview

This app allows users to track daily expenses, set budgets, analyze spending patterns, and switch between light/dark themes. It’s a fully responsive, offline-capable tool stored locally in the browser, making it perfect for personal use. I developed this project to demonstrate my ability to build practical, user-friendly applications with a focus on clean code and robust functionality.

---

## Features

- **Add & Edit Expenses**: Log expenses with amount, description, category, date, and currency.
- **Delete & Clear**: Remove individual or all expenses with confirmation.
- **Filter & Search**: Filter by category or search descriptions.
- **Budget Management**: Set and monitor budget with real-time status updates.
- **Analytics**: View top categories, daily averages, and period totals (week, month, year) with a pie chart.
- **Theme Toggle**: Switch between light and dark modes.
- **Multi-Currency**: Support for INR (₹), USD ($), and EUR (€).
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.

## Technologies Used

This project highlights a range of concepts and tools I’ve mastered:

- **HTML5**: Structured the app with semantic tags for accessibility and SEO.
- **CSS3**: Styled with custom variables, gradients, media queries, and animations for a responsive, modern UI.
- **JavaScript (ES6+)**: Implemented core logic, event handling, and local storage for data persistence.
- **Chart.js**: Integrated for dynamic pie chart visualizations of spending data.
- **Local Storage API**: Used to save expenses, budget, theme, and currency preferences offline.
- **DOM Manipulation**: Dynamically updated the UI with real-time data.
- **Event Listeners**: Handled user interactions like form submissions and button clicks.
- **Responsive Design**: Utilized CSS Grid, Flexbox, and breakpoints (768px, 480px).
- **Accessibility (a11y)**: Added ARIA attributes and keyboard navigation for inclusivity.
- **Netlify**: Deployed the app for free, showcasing my deployment skills.

## Project Structure

- **`index.html`**: Main HTML file with structure, including navigation, forms, and sections.

## Usage

1. **Add an Expense**:
   - Fill in the form (amount, description, category, date, currency) and click "Add Expense".
2. **View Summary**:
   - Check total expenses and count in the summary section.
3. **Set Budget**:
   - Enter a budget amount and click the set button to monitor spending.
4. **Analyze Spending**:
   - Switch tabs (week, month, year) to see analytics and a pie chart.
5. **Filter/Search**:
   - Use the dropdown or search bar to refine your expense list.
6. **Theme**:
   - Toggle light/dark mode via the sun/moon icon.

## Challenges & Solutions

- **Chart Loading**: Solved by dynamically loading Chart.js with a preloader.
- **Theme Consistency**: Used CSS variables to maintain uniform styling across modes.
- **Data Persistence**: Implemented local storage to retain user data offline.
- **Responsiveness**: Designed with media queries to adapt to all screen sizes.
